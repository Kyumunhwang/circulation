/swarm 중학교 2학년 과학 [순환] 단원의 '체순환(온몸 순환)'과 '폐순환' 과정을 시각적 이미지, 단계별 혈액 흐름 애니메이션, 그리고 상세한 생물학적 해설로 학습할 수 있는 고품질 인터랙티브 웹 시뮬레이션을 구축하라.

이 프로젝트는 교육용 소프트웨어 수준의 완성도를 목표로 하며, 아래 명시된 **8개의 전문 Sub-Agent**로 작업을 분할하여 병렬 및 순차적으로 수행하고, 마지막 **Verifier Agent**가 모든 결과물의 과학적 정확성, UI/UX 무결성, 코드 품질을 철저히 검수하여 최종 통합한다.

---

### 🤖 Sub-Agent 구성 및 상세 역할·목표 명세

#### 1. `Curriculum-Architect-Agent` (교육과정 및 과학적 팩트 설계자)
* **목표:** 대한민국 중학교 2학년 과학 교육과정(성취기준 [9과11-02] 혈액의 순환 경로와 기능)에 완벽히 부합하는 데이터 스키마 및 학습 시나리오 설계.
* **상세 역할:**
  * 심장의 4개 방(우심방, 우심실, 좌심방, 좌심실)과 판막(이첨판/삼첨판/반월판의 위치와 역류 방지 원리), 주요 혈관(대동맥, 대정맥, 폐동맥, 폐정맥)의 정확한 해부학적 연결 구조 정의.
  * **폐순환 경로:** `우심실 → 폐동맥 → 폐의 모세혈관(기체 교환: O₂ 흡수, CO₂ 방출) → 폐정맥 → 좌심방`의 단계별 상태 데이터화.
  * **체순환 경로:** `좌심실 → 대동맥 → 온몸의 모세혈관(물질 교환: O₂·영양소 공급, CO₂·노폐물 흡수) → 대정맥 → 우심방`의 단계별 상태 데이터화.
  * 학생들이 가장 많이 혼동하는 오개념('동맥=동맥혈, 정맥=정맥혈'이라는 착각을 교정하기 위한 폐동맥[정맥혈]과 폐정맥[동맥혈] 비교 포인트)을 학습 핵심 노트로 구조화.
  * `curriculumData.json` 파일로 모든 단계의 명칭, 혈액의 종류(동맥혈/정맥혈), 산소 포화도 변화, 교사용/학생용 상세 설명 텍스트 출력.

#### 2. `Visual-Asset-Curator-Agent` (시각 자료 및 SVG/이미지 에셋 제작자)
* **목표:** 학생들이 직관적으로 이해할 수 있는 해부학적 도식(SVG) 및 단계별 시각 자료(현미경 사진 스타일 그래픽, 기체 교환 모식도) 생성 및 매핑.
* **상세 역할:**
  * 해부학적 정확성과 교육적 가독성을 동시에 갖춘 고해상도 인터랙티브 SVG 심장 및 순환계 벡터 다이어그램 설계(각 심방/심실, 혈관, 모세혈관 망에 고유 ID 부여하여 CSS/JS 제어 가능하도록 설계).
  * 주요 6개 거점(심장 단면, 폐포와 모세혈관 기체 교환, 조직세포와 모세혈관 물질 교환, 동맥·정맥·모세혈관 단면 비교, 적혈구의 산소 운반 상태)에 대한 고품질 일러스트/다이어그램 에셋(SVG 및 Canvas 렌더링 그래픽) 제작.
  * 동맥혈(선홍색 `#E63946`)과 정맥혈(암적색/푸른빛 강조 `#457B9D`)의 색채 대비를 명확히 하여 혈액의 상태 변화를 시각적으로 즉각 인지할 수 있도록 팔레트 표준화.

#### 3. `Simulation-Engine-Agent` (혈액 흐름 물리 및 애니메이션 엔진 개발자)
* **목표:** 실제 혈액의 순환 속도와 심장 박동(수축기/이완기)에 연동되는 부드러운 입자(적혈구) 이동 시뮬레이션 엔진 구현.
* **상세 역할:**
  * SVG Path 및 HTML5 Canvas를 결합하여 적혈구 입자들이 심장의 4개 방과 각 혈관을 따라 끊김 없이 순환하는 입자 시스템 구현.
  * **동적 상태 변화:** 입자가 '폐 모세혈관'을 통과할 때 암적색에서 선홍색으로 서서히 변색되고, '온몸 모세혈관'을 통과할 때 선홍색에서 암적색으로 변색되는 실시간 컬러 보간(Color Interpolation) 로직 구현.
  * **심장 박동 연동:** 심방 수축 → 심실 수축(판막 개폐 애니메이션) → 이완 주기에 맞춰 혈액 입자가 박동성(Pulsatile flow)으로 추진되도록 물리 가속도 적용.
  * 재생/일시정지, 배속 조절(0.5x, 1.0x, 2.0x), 단계별 스텝 이동(Next/Prev Step) 제어 API 제공.

#### 4. `Interactive-UI-Designer-Agent` (교실 수업용 UI/UX 및 레이아웃 설계자)
* **목표:** 전자칠판(프로젝터) 환경에서 교사가 학생들에게 보여주며 설명하기에 최적화된 직관적이고 가독성 높은 인터페이스 구축.
* **상세 역할:**
  * **3단 분할 대시보드 레이아웃:**
    * 좌측/중앙(60%): 메인 순환계 인터랙티브 시뮬레이션 뷰포트 (확대/축소, 특정 부위 클릭 포커싱 지원).
    * 우측 상단(20%): 선택된 구간(예: 폐동맥, 좌심실 등)의 상세 해부학 사진/확대 모식도 뷰어 갤러리.
    * 우측 하단(20%): 단계별 교사용 해설 카드(혈액 종류, 이동 방향, 물질 교환 원리, 핵심 질문 팁).
  * **모드 전환 컨트롤러:** [전체 순환 보기] / [폐순환 집중 모드] / [체순환 집중 모드] / [동맥혈·정맥혈 하이라이트 모드] 원클릭 토글 버튼 배치.
  * 교실 뒷자리 학생도 텍스트를 읽을 수 있도록 고대비 타이포그래피 및 반응형 폰트 스케일 적용.

#### 5. `Micro-View-Explainer-Agent` (미시 세계 모세혈관 물질 교환 모듈 개발자)
* **목표:** 거시적 순환 경로뿐만 아니라 모세혈관에서 일어나는 '기체 및 물질 교환'을 확대하여 보여주는 서브 시뮬레이션 팝업/패널 개발.
* **상세 역할:**
  * 사용자가 '폐의 모세혈관' 또는 '온몸의 모세혈관'을 클릭하면 활성화되는 **미시 확대 시뮬레이션 뷰** 구현.
  * **폐포 확대 뷰:** 폐포 내 높은 산소 분압에서 모세혈관으로 $O_2$ 분자가 확산되고, 혈액에서 폐포로 $CO_2$ 분자가 확산되는 입자 애니메이션과 설명 제공.
  * **조직세포 확대 뷰:** 모세혈관에서 조직세포로 $O_2$와 영양소가 이동하고, 조직세포에서 모세혈관으로 $CO_2$와 노폐물이 이동하는 과정 시각화.

#### 6. `Teacher-Presentation-Tool-Agent` (수업 보조 및 판서·퀴즈 도구 개발자)
* **목표:** 교사가 수업 중 실시간으로 화면을 제어하며 학생들의 이해도를 점검할 수 있는 교수학습 보조 기능 탑재.
* **상세 역할:**
  * **레이블 숨기기/보이기(블라인드 테스트 모드):** 심장의 4방과 혈관 이름을 가려두고 수업 중 학생들에게 질문을 던진 뒤 클릭하여 정답을 공개하는 기능.
  * **핵심 오개념 비교 팝업:** '동맥 vs 동맥혈', '정맥 vs 정맥혈'을 한눈에 비교하는 시각적 도표 모달 구현.
  * **형성평가 미니 퀴즈:** 순환 경로 순서 맞추기(드래그 앤 드롭 또는 클릭 순서 지정) 인터랙티브 미니 게임 5문항 내장.

#### 7. `Frontend-Integrator-Agent` (애플리케이션 아키텍처 및 상태 통합자)
* **목표:** 위 6개 에이전트가 생성한 데이터, 그래픽 에셋, 애니메이션 엔진, UI 컴포넌트를 단일 프레임워크(React/Vite 또는 순수 모던 HTML/CSS/JS 번들)로 무결점 통합.
* **상세 역할:**
  * 전역 상태 관리(현재 선택된 순환 모드, 활성화된 혈관/심장 부위 ID, 애니메이션 재생 상태, 레이블 표시 여부)의 일관성 보장.
  * 컴포넌트 간 이벤트 버블링 및 렌더링 병목 제거(60fps 애니메이션 성능 최적화).
  * 브라우저 환경에서 별도 외부 서버 의존성 없이 즉시 실행 가능하도록 로컬 에셋 번들링.

#### 8. `Verifier-Agent` (최종 과학적·기술적 무결성 검수관)
* **목표:** 모든 Sub-Agent의 산출물을 교차 검증하여 **과학적 오류 0건, UI 깨짐 0건, 런타임 에러 0건**을 보장하는 최종 품질 게이트키퍼 역할 수행.
* **상세 검수 체크리스트 (하나라도 불합격 시 해당 에이전트에 수정 재지시):**
  1. **[과학적 팩트 검증 - 최우선]:**
     * 폐동맥에 '정맥혈'이 흐르고, 폐정맥에 '동맥혈'이 흐르는 것으로 정확히 표현되고 색상도 일치하는가?
     * 좌심실의 근육벽이 우심실보다 두껍게 묘사되었으며, 대동맥과 연결되어 있는가?
     * 혈액의 순환 방향이 `심방 → 심실 → 동맥 → 모세혈관 → 정맥 → 심방` 순서를 절대 역행하지 않는가? (판막의 개폐 타이밍과 혈액 이동이 일치하는가?)
  2. **[시각 자료 및 SVG 무결성 검증]:**
     * 모든 혈관 경로(SVG Path)가 끊어지거나 엉뚱한 방(예: 좌심실과 폐동맥이 연결되는 오류)에 연결되지 않았는가?
     * 확대/축소 및 창 크기 조절 시 텍스트 겹침이나 SVG 클리핑(잘림) 현상이 없는가?
  3. **[인터랙션 및 교육 기능 검증]:**
     * '폐순환 집중 모드' 활성화 시 체순환 경로는 적절히 디밍(Dimming) 처리되고 폐순환 경로의 설명과 이미지만 정확히 포커싱되는가?
     * '레이블 숨기기' 기능 작동 시 모든 정답 텍스트가 완전히 가려지고, 개별 클릭 시 정상 공개되는가?
  4. **[코드 및 성능 검증]:**
     * 콘솔 에러(Console Error), 미사용 변수, 깨진 이미지 링크(404)가 전혀 없으며, 애니메이션 프레임 드랍 없이 매끄럽게 작동하는가?

### 📌 최종 출력 지시사항
모든 에이전트의 협업과 `Verifier-Agent`의 최종 승인 이후, 실행 가능한 전체 프로젝트 코드와 함께 교사가 바로 수업을 진행할 수 있도록 **시뮬레이션 조작 가이드 및 수업 활용 시나리오 요약**을 함께 제공하라.
