## 1. 실행 방법 (교실 오프라인 즉시 실행 & 개발 서버)

### A. 인터넷·서버 없이 바로 실행하기 (교실 수업 권장)
빌드된 단일 HTML 파일은 외부 서버나 CDN(외부 폰트·라이브러리) 의존성이 전혀 없는 **100% 독립 실행형(`singlefile`)**으로 패키징되어 있습니다.

1. 프로젝트 폴더의 `dist/index.html` 파일을 교실 전자칠판 PC로 복사하거나 바로 엽니다.
2. `dist/index.html`을 **더블클릭**하여 Chrome, Edge 등 웹 브라우저로 열면 즉시 시뮬레이션이 실행됩니다.
3. 인터넷 연결이 없는 과학실·교실 환경에서도 모든 애니메이션, 6종 해부학 일러스트, 미시 뷰, 형성평가 퀴즈가 정상 동작합니다.

### B. 개발 서버 실행 및 재빌드 (Windows PowerShell 기준)
> **주의:** Windows PowerShell에서 실행 정책(`ExecutionPolicy`)으로 `npm.ps1`이 차단된 경우, 반드시 `cmd /c npm ...` 형태로 실행하세요.

```powershell
# 1. 의존성 설치 (최초 1회)
cmd /c npm install

# 2. 개발 서버 실행 (고정 포트 3412 사용)
cmd /c npm run dev:circulation-sim
# 브라우저에서 http://localhost:3412 접속

# 3. 단일 실행 파일(dist/index.html) 빌드
cmd /c npm run build
```

## 2. 화면 구성 및 전자칠판 조작법

화면은 교실 뒤쪽에서도 글자가 선명하게 보이도록 고대비·대형 폰트 기반의 **3단 교사용 대시보드**로 구성되어 있습니다.

### ① 상단 제어 바 (`ModeController`)
* **4가지 순환 학습 모드 (원클릭 전환)**
  * **전체 순환 보기**: 심장(4방·4판막), 폐순환, 체순환 전 경로를 동시에 관찰합니다.
  * **폐순환 집중 모드**: `우심실 → 폐동맥 판막 → 폐동맥 → 폐의 모세혈관 → 폐정맥 → 좌심방` 구간만 선명하게 강조하고 체순환은 반투명 처리합니다.
  * **체순환 집중 모드**: `좌심실 → 대동맥 판막 → 대동맥 → 온몸의 모세혈관 → 대정맥 → 우심방` 구간만 강조하여 온몸 순환을 집중 설명합니다.
  * **동맥혈·정맥혈 하이라이트 모드**: 혈관 이름이 아니라 **산소 함량에 따른 혈액 색상**(선홍색 동맥혈 vs 암적색·청색 정맥혈)의 대비를 극대화합니다.
* **교사용 수업 보조 도구**
  * **👁️ 레이블 숨기기 (블라인드 테스트)**: 도표와 해설 카드의 구조 명칭을 모두 `?`로 가립니다. 활성화 시 `전체 공개` / `모두 가리기` 보조 버튼이 나타납니다.
  * **⚖️ 핵심 오개념 비교**: `동맥 vs 동맥혈`, `정맥 vs 정맥혈`, 특히 **폐동맥(정맥혈) vs 폐정맥(동맥혈)** 비교 팝업을 엽니다.
  * **📝 형성평가 퀴즈**: 객관식 3문항 + 순환 경로 순서 맞추기 2문항(총 5문항)을 전자칠판에서 즉시 풀이할 수 있는 팝업을 엽니다.
* **재생 및 단계 제어**
  * `◀ 이전 단계` / `다음 단계 ▶`: 순환 순서(전체 14단계, 집중 모드 시 해당 순환 6단계)를 한 단계씩 짚어 가며 설명합니다. 키보드의 **왼쪽/오른쪽 화살표(`←` / `→`)**로도 이동할 수 있습니다(팝업이 닫혀 있을 때).
  * `⏸ 일시정지` / `▶ 재생`: 심장 박동 주기와 적혈구(RBC) 이동을 원하는 순간에 멈춰 설명합니다.
  * 배속(`0.5x` · `1.0x` · `2.0x`): 판막 개폐와 혈류 가속을 천천히 관찰할 때는 `0.5x`를 권장합니다.

### ② 좌측/중앙 메인 시뮬레이션 뷰포트 (60% 영역)
* **상단 표시줄**: `동맥혈 (산소 풍부 · 선홍색)` / `정맥혈 (산소 부족 · 암적색)` 범례와 실시간 **심장 박동 주기**(`심방 수축` → `심실 수축` → `심실 이완`)가 동기화되어 표시됩니다.
* **전자칠판 확대/이동(Zoom & Pan) 조작**:
  * 우측 상단 `－` / `＋` 버튼으로 **75% ~ 200%**까지 확대·축소할 수 있습니다.
  * 100% 이상 확대한 상태에서는 화면을 손가락이나 마우스로 **드래그(Drag)**하여 판막이나 좌심실 벽 두께 부분을 화면 중앙으로 끌어올 수 있습니다.
  * `초기화` 버튼을 누르면 즉시 100% 중앙 정렬로 복귀합니다.
* **구조물 직접 클릭**: 심방·심실·판막·혈관 어느 부위든 터치/클릭하면 해당 구조가 노란색 테두리로 강조되며 우측 패널의 모식도와 해설이 즉시 바뀝니다.
* **하단 모세혈관 미시 뷰 바로가기**: `폐의 모세혈관 (기체 교환)` 또는 `온몸의 모세혈관 (물질 교환)` 버튼을 누르거나, 도표 내 모세혈관의 `🔬 미시 뷰` 배지를 클릭하면 확산 입자 시뮬레이션 창이 열립니다.

### ③ 우측 상단: 해부학 확대 모식도 갤러리 (`DetailGalleryPanel`)
* 선택한 구간과 연결된 6종의 고해상도 해부학 일러스트를 자동으로 띄워 줍니다.
  1. `심장 단면·벽두께` (좌심실 근육벽이 우심실보다 두꺼운 이유 비교)
  2. `폐포 기체교환`
  3. `조직 물질교환`
  4. `동맥·정맥·모세혈관` (혈관벽 두께 및 정맥 판막 비교)
  5. `적혈구 O₂ 운반` (산소 결합/해리에 따른 색 변화)
  6. `순환 통합 모식도`
* 상단 6개 썸네일 탭을 눌러 수업 흐름에 맞게 언제든 원하는 그림으로 전환할 수 있습니다.
* **2배 확대 및 크게 보기 조작**:
  * 패널 내 우측 상단의 `1x` / `2x` (`초기화`) 버튼을 누르면 모식도 이미지가 가로·세로 **2배(200%)**로 확대되며, 마우스·터치 드래그 또는 스크롤로 세부 부위를 이동하며 살펴볼 수 있습니다.
  * 헤더의 **`🔍 2배 크게 보기`** 버튼을 클릭하거나 모식도 영역을 **더블클릭**하면 전용 확대 모달(`920×640`, `2x` 기본)이 열려 교실 전체 화면에 선명하게 띄울 수 있습니다(모달 내부 `1x`/`2x` 전환, 6종 탭 전환, `ESC`·배경 클릭 닫기 지원).

### ④ 우측 하단: 단계별 교사용 해설 카드 (`TeacherExplanationCard`)
* 선택한 구간의 **혈액 종류 배지**, **산소(O₂) 포화도**, **혈액 이동 방향**, **물질·기체 교환 원리**, **구조 및 압력 특징**, 그리고 학생에게 바로 던질 수 있는 **💡 수업 발문 팁**을 제공합니다.

## 3. 기능별 수업 활용 팁 (교사용 노하우)

1. **블라인드 테스트 모드 활용 (`👁️ 레이블 숨기기`)**
   * 개념 설명 후 도표 명칭을 모두 숨긴 상태에서 학생을 지목하거나 모둠별로 맞히게 한 뒤, 도표의 `?` 배지 또는 해설 카드의 `정답 공개` 버튼을 눌러 하나씩 정답을 확인하세요.
   * 우측 해설 카드의 이동 방향 문장에서도 해당 구조물 이름이 `[ ??? ]`로 자동 마스킹되므로 힌트 노출 없이 질문할 수 있습니다.
2. **좌심실 근육벽 & 판막 역류 방지 지도**
   * 배속을 `0.5x`로 낮추고 심장 부분을 `150%`로 확대한 뒤, **심실 수축** 순간에 방실판막(삼첨판·이첨판)이 닫히고 반월판(폐동맥 판막·대동맥 판막)이 열리며 혈액이 한 방향으로만 뿜어져 나가는 모습을 보여주세요.
   * `좌심실`을 선택해 우측 상단 `심장 단면·벽두께` 그림과 하단 `⚡ 좌심실 근육벽 두께 핵심 포인트`를 함께 짚어주세요.
3. **모세혈관 미시 뷰 (`MicroViewModal`) 활용**
   * `농도 차 확대(O₂/CO₂↑)` 토글을 켜서 폐포에서는 O₂가 적혈구로 들어가 `정맥혈(청색) → 동맥혈(선홍색)`으로 변하고, 온몸의 조직세포에서는 O₂와 영양소가 빠져나가 `동맥혈(선홍색) → 정맥혈(청색)`으로 변하는 과정을 비교 설명하세요.
   * 하단 범례(`O₂`, `CO₂`, `영양소`, `노폐물`)를 클릭하거나 마우스를 올리면 해당 입자의 이동 원리 설명이 강조됩니다.
4. **핵심 오개념 교정 (`⚖️ 핵심 오개념 비교`)**
   * *"동맥에는 무조건 동맥혈이 흐른다"*는 대표 오개념을 깨기 위해 `폐동맥(심장에서 나감=동맥, 산소 부족=정맥혈)`과 `폐정맥(심장으로 들어옴=정맥, 산소 풍부=동맥혈)` 카드를 띄우고 비교 표를 짚어주세요.
5. **형성평가 미니 퀴즈 (`📝 형성평가 퀴즈`)**
   * **순환 경로 순서 맞추기(2번·5번 문항)**는 보기 버튼을 순서대로 클릭해 빈칸을 채우고, `↑`/`↓` 버튼으로 순서를 수정한 뒤 `정답 확인`을 누르는 참여형 문제입니다. 전자칠판 앞으로 학생이 나와 직접 순서를 클릭해 보게 하면 집중도가 크게 높아집니다. (모달 닫기는 `ESC` 키 또는 바깥 배경 클릭 지원)

| **정리 (5분)** | `👁️ 레이블 숨기기` | 방과 판막 명칭 4~5개를 무작위로 가리고 구두 퀴즈로 핵심 구조 복습 |

### [2차시] 모세혈관의 물질 교환, 동맥혈·정맥혈 오개념 교정 및 형성평가
| 수업 단계 (시간) | 활용 화면·기능 | 교사 발문 및 교수-학습 활동 |

| **도입 (5분)** | `동맥혈·정맥혈 하이라이트 모드` | 전체 순환에서 붉은 구간(폐정맥·좌심·대동맥)과 파란 구간(대정맥·우심·폐동맥)이 갈리는 두 지점이 어디인지 찾기 |

| **평가 (13분)** | `📝 형성평가 퀴즈` (1~5번) | 학생 참여로 객관식 3문항 + 폐순환·체순환 순서 맞추기 2문항 풀이. 오답 시 즉시 해설 확인 및 `다시 풀기` 활용 |
| **마무리 (5분)** | `눈 가리기(블라인드)` `전체 공개` | 혈액의 일방통행(심방→심실→동맥→모세혈관→정맥→심방) 핵심 요약으로 차시 종료 |
